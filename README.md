## 🔧 Troubleshooting Common Issues

### "Windows protected your PC" warning
- This happens with all new software. Click **More info** → **Run anyway**. It's just Microsoft being cautious.

### App won't start or shows a blank screen
1. Close the app window completely.
2. Restart your computer.
3. Open the app again from the Start Menu (search "Ghostfolio").
4. If still blank, uninstall and reinstall using the same download link.

### I forgot my local password
- No problem. Just uninstall the app (Settings → Apps → Ghostfolio → Uninstall) and reinstall. Your portfolio data is stored separately in your user folder and will still be there—but make sure you don't delete that folder during uninstall.

### Need to move to a new computer?
- Your data lives in `C:\Users\YourName\GhostfolioData`. Copy this folder to your new machine after installing the app, and all your history comes with it.
